# flipwits-site

The public site for Flip Wits, served by GitHub Pages at https://flipwits.hearthandwit.com. Plain HTML and one stylesheet, with no build step and no outside requests.

The look matches https://hearthandwit.com: `style.css` starts with a copy of that site's stylesheet. When `style.css` or `favicon.svg` changes, bump the `?v=` tag on its links in all three pages.
